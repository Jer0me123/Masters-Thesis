\chapter*{Appendix A: Occupation List}
\addcontentsline{toc}{chapter}{Appendix A: Occupation List}

The following 200 occupations, listed alphabetically, constitute the full profession set used for profession-conditioned image retrieval from Re-LAION-5B and for image generation using Stable Diffusion v1.5. The set was constructed by sampling job titles systematically across all ten ISCO-08 major groups, ensuring representative coverage of skill levels, professional domains, and social prestige ranges.
